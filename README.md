# 豆格 · 拼豆图纸工坊

这是可以直接上传到 GitHub Pages 的静态网站。

1. 将本目录中的全部文件与 assets 文件夹上传到 Public 仓库根目录。不要上传 ZIP 文件本身。
2. Settings → Pages → Deploy from a branch → main → / (root) → Save。
3. 等待部署完成，使用 Pages 页面显示的网址。以后更新这些文件会自动重新发布。

index.html 必须位于仓库根目录；assets 文件夹必须完整上传。
.nojekyll 是隐藏文件，建议一并上传。macOS 按 Command + Shift + . 可显示隐藏文件。

无需账号或 API key。用户照片在本地处理。C01 等为自定义色号，不对应品牌官方色号。
