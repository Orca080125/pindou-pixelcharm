# 豆格 · MARD 221 色版

这是可以直接上传到 GitHub Pages 的静态网站。

1. 将本目录中的全部文件与 assets、palettes 文件夹上传到 Public 仓库根目录。不要上传 ZIP 文件本身。
2. Settings → Pages → Deploy from a branch → main → / (root) → Save。
3. 等待部署完成，使用 Pages 页面显示的网址。以后更新这些文件会自动重新发布。

index.html 必须位于仓库根目录；assets 文件夹必须完整上传。
.nojekyll 是隐藏文件，建议一并上传。macOS 按 Command + Shift + . 可显示隐藏文件。

本版本使用 MARD 221 色，支持 2–221 色的颜色上限，默认 221 色。
图纸每格、PNG 图例和 CSV 用量表均使用 A5、H7 等 MARD 色号。
图片在用户设备本地处理，无需登录或 API key。
屏幕 RGB 是近似值，实际配色请以实物色卡为准。
数据与授权说明见 palettes/SOURCES.md 和 palettes/LICENSE-beadcolors.txt。
